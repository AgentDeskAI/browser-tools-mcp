BrowserTools MCP

Page actions stay off until you turn them on here.

Quitting the browser turns this off again. It covers the tab list, reading a tab, navigation, and soft click and type. Navigation and soft input also need the server to be started with --allow-input. Script evaluation needs --allow-eval and the DevTools panel switch. These flags have no environment-variable form.

One http(s) origin per line. Listed origins are never acted on.

Reading a tab and soft input need host access for that site. Local pages are already allowed. This asks Chrome for access. It does not hide the debugging banner, and the debugging banner stays off unless a DevTools capture attaches the debugger.

8-hour log

Off until you turn it on. Console and network for a checked tab or site stay on this machine for 8 hours, then they are deleted. Cookies and Authorization are removed before they are stored.

This does not hide the debugging banner and does not click or drive the page. An agent can read the log only for a tab or site you enabled, and only inside the last 8 hours. Sites other than this machine need “Allow reading pages you have open” above.
