BrowserTools MCP

Page actions stay off until you turn them on here.

Quitting the browser turns this off again. It covers the tab list, reading a tab, navigation, and soft click and type. Navigation and soft input also need the server to be started with --allow-input. Script evaluation needs --allow-eval and the DevTools panel switch. These flags have no environment-variable form.

One http(s) origin per line. Listed origins are never acted on.
